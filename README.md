# TP 4 – Programmation Orientée Objet en PHP

Ce dépôt contient les exercices et réponses du **TP 4** sur la POO en PHP (PHP 8.1+).

## Contenu du dossier
- `partie0.php` : Première classe (`Voiture`)
- `partie1.php` : Visibilité et encapsulation (`Personne`)
- `partie2.php` : Constructeurs, promotion de propriétés et destructeur
- `partie3.php` : Méthodes magiques (`__get`, `__set`, `__isset`, `__unset`)
- `partie4.php` : Représentation textuelle (`__toString`)
- `partie5.php` : Sérialisation (`__serialize`, `__unserialize`)
- `partie6.php` : Héritage (`extends`, `parent::`, `final`, `readonly`)
- `partie7.php` : Mise en pratique (`Compte` bancaire)
- `reponses.md` : Réponses aux questions du TP et questions de synthèse
